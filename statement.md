# Project Statement: Age & DOB Calculator

## Problem Statement
Calculating exact age in years, months, and days or reverse-calculating a date of birth from an individual's age manually can be prone to human error[cite: 2, 3]. This project provides a quick and modular command-line tool to accurately compute age and birth dates given basic current calendar inputs[cite: 2, 3, 4].

## Scope of the Project
- The current implementation accepts numeric inputs for current dates and birth dates/ages to perform mathematical offset calculations[cite: 2, 3, 4].
- The application runs via a Python terminal interface[cite: 4].
- Future scope includes adding built-in system clock fetching (`datetime` library) to automatically pre-fill current dates and validation for dynamic leap years and varying month lengths.

## Target Users
- Students and academic record managers requiring quick age/DOB verification[cite: 2, 3].
- Anyone needing precise age calculations down to day level without manual date arithmetic[cite: 2, 3].

## High-Level Features
- **Calculate Age:** Input ongoing date and birth date to display total years, months, and days[cite: 2, 4].
- **Calculate Birth Year/Date:** Input ongoing date and current age to determine birth date[cite: 3, 4].
- **Command-Line Interface:** Menu-driven menu selection system[cite: 4].
