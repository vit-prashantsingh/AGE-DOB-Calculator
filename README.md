# AGE/DOB Calculator

## Overview
Age & DOB Calculator is a Python-based command-line utility designed to perform two primary calculations:
1. **Age Calculation:** Determines a person's precise age in years, months, and days based on the current date and their date of birth[cite: 2, 4].
2. **DOB Calculation:** Determines a person's date of birth based on the current date and their exact age[cite: 3, 4].

## Features
- **Age Computation Module:** Takes the current date and birth date parameters to compute the precise age difference[cite: 2, 4].
- **Date of Birth Module:** Takes the current date and age parameters to extrapolate the original birth date[cite: 3, 4].
- **Interactive CLI:** Simple interactive menu for easy navigation between modes.
